# 4.2.1.3.3.1 Do funcionamento do gerundivo

O **gerundivo** expressa um evento verbal dependente de outro evento principal.

Ele é utilizado em funções como:

- simultaneidade
- finalidade
- sequência funcional
- ação contextual
- subordinação verbal
- “ao fazer”
- “fazendo”
- “para fazer”

O gerundivo não altera a estrutura argumental do verbo.

Ele apenas modifica o valor sintático e aspectual da forma verbal.

---

# 4.2.1.3.3.1.1 Estrutura Geral

O gerundivo é marcado por sufixos verbais posicionados ao final do complexo verbal.

Nos verbos transitivos, o sufixo gerundivo ocorre:

- após o sufixo de objeto, quando houver
- diretamente após a raiz, quando não houver objeto expresso

---

# 4.2.1.3.3.1.2 Sufixos Gerundivos

| Valor | Raiz consonantal | Raiz nasal | Raiz vocálica |
| --- | --- | --- | --- |
| presente | -ko | -ngo | -go |
| futuro | -ke | -nge | -ge |
| negativo presente | -kemo | -ngemo | -gemo |
| negativo futuro | -keme | -ngeme | -geme |

---

# 4.2.1.3.3.1.3 Estrutura Morfológica

## 4.2.1.3.3.1.3.1 Forma positiva presente

```
verbo + -ko
```

## 4.2.1.3.3.1.3.2 Forma positiva futura

```
verbo + -ke
```

## 4.2.1.3.3.1.3.3 Forma negativa presente

```
verbo + -kemo
```

## 4.2.1.3.3.1.3.4 Forma negativa futura

```
verbo + -keme
```

---

# 4.2.1.3.3.1.4 Posição nos Verbos Transitivos

Quando houver sufixo de objeto, o gerundivo ocorre após ele.

## 4.2.1.3.3.1.4.1 Estrutura

```
raiz + (objeto) + gerundivo
```

---

# 4.2.1.3.3.1.5 Regras Concatenativas

Os sufixos gerundivos sofrem adaptações fonológicas conforme a forma final da raiz verbal ou do sufixo precedente.

## 4.2.1.3.3.1.5.1 Raiz Final em Consoante Oral

Se a raiz terminar em consoante oral:

- a consoante final desaparece
- o sufixo é adicionado normalmente

## 4.2.1.3.3.1.5.2 Estrutura

```
C + ko/ke → ko/ke
```

---

## 4.2.1.3.3.1.5.3 Raiz Final em Consoante Nasal

Se a raiz terminar em consoante nasal:

- a consoante final desaparece
- o K do sufixo nasaliza para NG

## 4.2.1.3.3.1.5.4 Estrutura

```
N + ko/ke → ngo/nge
```

---

## 4.2.1.3.3.1.5.5 Raiz Final em Vogal

Se a raiz terminar em vogal:

- o sufixo permanece
- o K sonoriza para G

## 4.2.1.3.3.1.5.6 Estrutura

```
V + ko/ke → go/ge
```

---

# 4.2.1.3.3.1.6 Exemplos Conceituais

| Forma subjacente | Resultado |
| --- | --- |
| tak + ko | tako |
| man + ko | mango |
| yua + ko | yuago |
| tak + ke | take |
| man + ke | mange |
| yua + ke | yuage |

---

# 4.2.1.3.3.1.7 Polaridade

O gerundivo possui distinção própria entre:

- positivo
- negativo

Diferentemente do indicativo e do optativo, a negação do gerundivo é incorporada diretamente ao próprio sufixo modal.

---

# 4.2.1.3.3.1.8 Relação Temporal

O gerundivo distingue:

| Valor | Função |
| --- | --- |
| presente | simultaneidade ou ação em curso |
| futuro | finalidade ou ação posterior |

---

# 4.2.1.3.3.1.9 Papel Sintático

O gerundivo normalmente ocorre em estruturas dependentes.

Ele pode introduzir:

- ações simultâneas
- ações preparatórias
- finalidade
- contexto aspectual
- subordinação verbal

A forma gerundiva normalmente possui menor independência sintática que o indicativo.
