# 4.2.1.3.4.1 Do funcionamento do optativo

O **optativo** expressa desejo, expectativa, intenção, possibilidade desejada ou eventos esperados pelo falante.

É utilizado em contextos como:

- desejos
- esperanças
- pedidos brandos
- convites
- intenções
- “tomara”
- “que…”

O optativo não altera a estrutura argumental do verbo. Seu funcionamento é morfologicamente semelhante ao indicativo.

Todos os tipos verbais podem ocorrer no optativo:

- intransitivos ativos
- intransitivos estativos
- transitivos

---

# 4.2.1.3.4.1.1 Estrutura Geral

O optativo é formado pela adição de um prefixo modal antes do prefixo pessoal.

### 4.2.1.3.4.1.1.1 Antes de prefixo consonantal

```
si- + prefixo pessoal + raiz + (objeto)
```

### 4.2.1.3.4.1.1.2 Antes de prefixo vocálico

```
sh- + prefixo pessoal + raiz + (objeto)
```

---

# 4.2.1.3.4.1.2 Prefixo Modal

O modo optativo possui dois alomorfes:

| Ambiente | Prefixo | Prefixo pós negação |
| --- | --- | --- |
| antes de consoante | si- | zi- |
| antes de vogal | sh- | j- |

A escolha depende da forma inicial do prefixo pessoal subsequente.

---

# 4.2.1.3.4.1.3 Polaridade

O optativo distingue:

- positivo
- negativo

A negação precede o prefixo modal optativo.

---

# 4.2.1.3.4.1.3.1 Estrutura da Negação

```
negativo + optativo + prefixo pessoal + raiz
```

---

# 4.2.1.3.4.1.4 Intransitivos Ativos

Os verbos intransitivos ativos mantêm os mesmos prefixos pessoais do indicativo.

### 4.2.1.3.4.1.4.1 Positivo

```
optativo + prefixo ativo + raiz
```

### 4.2.1.3.4.1.4.2 Negativo

```
negação + optativo + prefixo ativo + raiz
```

---

# 4.2.1.3.4.1.5 Intransitivos Estativos

Os verbos estativos mantêm os mesmos prefixos do indicativo.

### 4.2.1.3.4.1.5.1 Positivo

```
optativo + prefixo estativo + raiz
```

### 4.2.1.3.4.1.5.2 Negativo

```
negação + optativo + prefixo estativo + raiz
```

---

# 4.2.1.3.4.1.6 Transitivos

Os verbos transitivos mantêm:

- prefixos portmanteau
- sufixos de objeto
- funcionamento hierárquico

do indicativo.

O optativo apenas adiciona a marca modal antes do complexo verbal.

---

# 4.2.1.3.4.1.7 Estrutura

```
optativo + prefixo verbal/portmanteau + raiz + (objeto)
```

### 4.2.1.3.4.1.7.1 Negativo

```
negação + optativo + prefixo verbal/portmanteau + raiz + (objeto)
```

---

# 4.2.1.3.4.1.8  Relação com o Indicativo

O optativo preserva praticamente toda a morfologia verbal do indicativo.

As principais diferenças são:

- presença do prefixo modal si-/sh-
- valor semântico desiderativo ou volitivo
- não declinação para o futuro

---

# 4.2.1.3.4.1.9 Papel Sintático

O optativo pode ocorrer em:

- orações independentes
- subordinadas
- expressões exclamativas
- construções volitivas

Ele não implica necessariamente irrealidade, apenas que o evento é apresentado sob perspectiva desiderativa ou intencional.
